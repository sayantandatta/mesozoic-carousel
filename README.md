# Mesozoic Carousel

A simple web page that shows dinosaurs at random in an endless carousel. Each new dinosaur swivels in from the right, then says its name and what it ate.

Live site: https://sayantandatta.github.io/mesozoic-carousel/

- 15 dinosaurs from the Triassic, Jurassic and Cretaceous, with no repeats until all 15 have been shown
- Speech uses the browser's built-in voice (tap **Start** first, since browsers block sound until you tap)
- Fossil photos are loaded from Wikipedia; if a photo can't load, the page shows its own drawing of that dinosaur
- Controls: Start/Pause, Next, Voice on/off. Keyboard: Space to pause, → for next

It is one self-contained `index.html` with no build step, published with GitHub Pages.
