# Mesozoic Carousel

An endless carousel of 15 dinosaurs. A random one swivels in from the right, says its name and what it ate, then the next one turns in. No dinosaur repeats until all 15 have been shown.

Live site: https://sayantandatta.github.io/mesozoic-carousel/

- Press **Start** (browsers need a tap before a page can speak).
- **Pause**, **Next** and **Voice on/off** controls. Space pauses, → skips.
- Fossil photos come from Wikipedia. If a photo can't load, the page shows its own drawing of that dinosaur.
- Speech uses the browser's built-in voice (Web Speech API), so the voice depends on the device.

One static file, `index.html`. No build step.
